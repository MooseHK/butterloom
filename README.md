# butterloom

Static GitHub Pages-ready storefront for Butterloom with:

- South Asian ethnic-fashion inspired homepage and product catalog
- Amazon-style cart and checkout flow (fully client-side)
- Admin dashboard for multi-user inventory/order management
- Activity logs for auditable admin actions

## Run locally

```bash
python -m http.server 8000
```

Then open `http://127.0.0.1:8000`.
